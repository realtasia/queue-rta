# realTasia queue archive snapshot

This repository is a sanitised archival snapshot of the realTasia background-processing service. The historical software dates from the original operating period. This README, `COMMIT_COMMENTARY.md`, `SANITISATION.md`, `NO-LICENCE.md` and the synthetic configuration example are editorial material added during the 2026 archive project.

The public form is one snapshot commit. It does not expose the private historical Git objects. Historical logs, captured payloads and live worker configuration are omitted. The application source and queue/email architecture remain available for review.

The archive follows the [realTasia Archive and Editorial Policy](https://github.com/realtasia/.github/blob/main/ARCHIVE_POLICY.md). No open-source licence is granted by this repository.

## Reading the archive

- `COMMIT_COMMENTARY.md` is a contemporary architectural reading of selected commits.
- `SANITISATION.md` records publication transformations and the metadata checkpoint.
- `iron.json.example` preserves the worker configuration shape using synthetic values.
- `NO-LICENCE.md` states the present reuse position.

The private archival master and private transformation records remain the evidentiary record for the snapshot.

## Historical record

This repository contains the historical commits with detected credential values redacted, alongside the modern archival snapshot. See [SANITISATION.md](./SANITISATION.md) for the snapshot changes.
